# Motion Room 0.9.40

Motion Room brings Source Filmmaker-style animation controls and workflow to Blender. This repository contains the two installable builds for supported Blender versions.

## Download the right file

| Blender version | File |
| --- | --- |
| Blender 4.0–4.1 | `motion-room-0.9.40-blender-4.0-4.1-legacy.zip` |
| Blender 4.2–5.2 | `motion-room-0.9.40-blender-4.2-5.2.zip` |

Do not unzip the file before installing it.

## Install on Blender 4.0 or 4.1

1. Download `motion-room-0.9.40-blender-4.0-4.1-legacy.zip`.
2. Open Blender and go to **Edit > Preferences > Add-ons**.
3. Click **Install**, select the downloaded ZIP, and confirm.
4. Search for **Motion Room** and enable its checkbox.
5. Close Preferences. A **Motion Room** workspace tab will be available at the top of Blender.

## Install on Blender 4.2 through 5.2

1. Download `motion-room-0.9.40-blender-4.2-5.2.zip`.
2. Open Blender and go to **Edit > Preferences > Get Extensions**.
3. Open the menu in the upper-right and choose **Install from Disk**.
4. Select the downloaded ZIP and confirm.
5. If needed, open **Installed Extensions**, find **Motion Room**, and enable it.
6. Close Preferences. A **Motion Room** workspace tab will be available at the top of Blender.

## Basic use

- Open the **Motion Room** workspace tab.
- Select an armature or animated object.
- Use the Motion, Graph, Clip, and Timeline modes to select controls, pose, edit keys, and work with time selections.
- Press **I** over a Motion Room viewport to insert Motion Room keys.
- Use **Window > Open Motion Room** if the workspace tab is hidden.
- Save normally as a `.blend`; Motion Room produces ordinary Blender animation keys.

## Update or remove

To update, install the newer ZIP for your Blender version over the existing installation. To remove Motion Room, open Blender Preferences, find **Motion Room** under Add-ons or Installed Extensions, and choose **Remove** or **Uninstall**.

## Compatibility

These Windows builds support Blender 4.0 through 5.2. The legacy package is required for Blender 4.0 and 4.1 because those versions predate Blender's Extensions system. The standard package is for Blender 4.2 and newer.
